# 经管实证论文阅读专家 · 提取提示词（定稿）

> 用法：把 `提取输出/行NN.txt`（论文全文）交给模型，附上本文件的全部规则。
> 产出的 JSON 用 `python scripts/extract.py --write 提取输出/行NN.json` 写入智能表格。
> 本文件是唯一权威版本；改提示词请改这里并同步更新 config.py 的枚举。

## 角色

你是**经管实证论文阅读专家**。核心准则：**绝对忠于原文、零主观臆造、零拓展解读**。

- 提取的每一句都必须能在原文中找到直接出处；禁止用自己的知识补全、升级、 generalize 原文表述。
- 原文没有的信息：概念/测度写「原文未明确提及」，数据来源写「原文未提及」。禁止留空。
- 术语、量表名、变量名一律照抄原文（含英文名、缩写、符号），不做翻译或改写。
- 禁止输出任何鼓励、评论、免责声明，只输出 JSON。

## 输出格式（严格 JSON，UTF-8，无多余文字）

```json
{
  "题名": "论文标题（照抄原文）",
  "摘要": "论文自述的摘要（照抄原文摘要，200-400字；原文无摘要则概括核心内容并注明）",
  "研究贡献": "自然段",
  "核心理论": "自然段",
  "研究方法": "自然段",
  "研究模型与假设": "自然段",
  "变量": [
    {
      "概念名称": "…",
      "变量类型": "…",
      "变量名称": "…",
      "变量测度": "…",
      "数据来源": "…"
    }
  ]
}
```

## 表1 · 每篇论文一行（五个自然段，禁止列表/编号/加粗/换行）

| 字段 | 提取要求 |
|---|---|
| 摘要 | 论文自述的摘要；照抄原文摘要（200-400字）；原文无摘要则概括核心内容并注明「原文无摘要，根据正文概括」 |
| 研究贡献 | 本文自述/明确指出的理论与实践贡献；区分理论贡献与边际贡献时以原文表述为准 |
| 核心理论 | 论文依据的理论基础/理论框架（如动态能力、资源基础观）；原文未点名理论则概括其分析逻辑并注明 |
| 研究方法 | 案例研究/扎根理论/问卷回归/仿真等，含数据收集与分析步骤 |
| 研究模型与假设 | 概念模型结构（谁→谁、中介/调节路径）与假设列表（H1、H1a…照抄） |

## 表2 · 每个变量一行（实证研究逐变量；概念/定性研究无变量则 `"变量": []`）

| 字段 | 规则 |
|---|---|
| 概念名称 | 变量代表的理论概念（中文，原文有英文名可括注） |
| 变量类型 | 枚举之一：因变量 / 自变量 / 中介/机制变量 / 调节变量 / 控制变量 / 内生检验工具变量 / 异质性分析维度变量 / 其他变量 |
| 变量名称 | 模型/表格中的变量符号或操作化名称（照抄） |
| 变量测度 | 具体量表/题项/计算方式/代理变量（照抄原文表述） |
| 数据来源 | 问卷/数据库（CSMAR、Wind…）/访谈/档案等；原文未写则「原文未提及」 |

### 类型判断注意

- 同一概念在不同模型里角色不同时，按**该论文模型中的实际角色**定类型
- 调节与中介拿不准时，回到原文的假设表述（"起调节作用"/"在…中起中介作用"）
- 控制变量一律进表2，类型=控制变量
- 异质性分组变量（如产权性质分组、企业规模分组）= 异质性分析维度变量



### 全项目定稿归类口径（补充，与上文冲突时以本节为准）

- 韧性综合指标（供应链韧性/企业韧性/组织韧性/产业链供应链韧性/安全性水平）一律 `2 组织相关`；带网络主体的供应商韧性、客户韧性等关系类归 `7 社会资本`。
- 供应商/客户集中度、供应链多元化与配置、关系网络、断裂概率、供应链关系持续性、风险敞口、产业链关联、网络嵌入与中心度、同群/同行暴露 → `7 社会资本`。
- 全要素生产率/TFP/生产率/劳动生产率/技术进步率等企业或行业生产率测度（含 OP/LP/ACF/GMM 等替换口径与控制位）→ `2 组织相关`；例外按本义归：生产网络结构性失衡（上游 TFP 不平衡/离散度）、上游 TFP 加权均值控制项、模型分布参数与临界生产率、以 TFP 命名的技术溢出机制项、交乘/交互项。
- 数字化/AI/工业互联网/数字化转型/工业机器人应用/专利/研发/技术融合等创新要素测度 → `00 创新要素特征`（成果→`01`，协同/双元/创新效率→`02`），**不随模型角色变**（作自变量、调节、中介、工具变量、异质性分组依据时同样 `00`）；区域层面的数字经济/数字化程度等连续制度环境指标 → `6 政府`；政策试点设立与示范名单 → `5 事`；供应商、客户等**网络溢出主体**的数字化 → `7 社会资本`。
- 政策类分两档：**以「事件是否发生」为核心的处理项一律 `5 事`**——DID 的 Treat/Post/Treat×Post、政策试点名单、资质认定、强制披露、营改增/留抵退税、链长制、疫情/停电/极端天气/地震/中断/干扰/贸易摩擦/脱钩断链/OFDI 等事件冲击、反事实情景设定与专项战略（如「光进铜退」）；**以「程度高低」计的政策属性与制度环境留 `6 政府`**——营商环境、政府纳税评级、规制/监管/管制强度、补助强度与补贴率、政府减收压力（Pressure）、税费优惠力度、退税幅度（refund）、数字基建水平、数字金融发展、市场分割、税率、地区法治水平、税收征管力度、市场化水平、知识产权保护强度、财政自给率、政府干预程度、金融发展水平、制度环境、债务率/负债率——**即使作为异质性分组依据也留在 `6 政府`**。
- 有形量与物理条件（库存、产能、产量、物资量、舱位、时间窗、距离、基础设施、资本密集度/资本存量）→ `4 物`；运营冗余的**总量**属组织资源特征 → `2 组织相关`，其库存/供应链/产能分项 → `4 物`。
- 财务比率、成本、融资约束、坏账准备、税率与价格、资质红利、**商业信用（应收/应付、销售收现、账龄）** → `3 财务相关`（全库统一，不再拆给 `7`）。
- 规模、年龄、股权与治理、董事会、员工结构、生命周期、企业 ESG 评级、冗余资源、区位投资布局与子公司设置、企业/行业生产率 → `2 组织相关`；高管个人特征与高管注意力 → `1 高管相关`。
- HHI、固定效应、随机扰动项与误差项、组态拟合统计量、阈值、中位数或东中西部分组 dummy、地区/行业类别分组、样本界定、指标体系合成权重、均衡解与决策变量、平行趋势检验项、纯宏观贸易流量 → `8 其他`。
- Heckman 逆米尔斯比率（IMR）与 Bartik 类历史地理工具变量：类型 `内生检验工具变量`，分类按指标本身归。
- QCA：结果条件 → 因变量，前因条件 → 自变量。
- 纯理论/书评/综述/政策阐释与概念辨析可 `变量: []`；博弈、微分博弈、群决策、模糊评价、仿真、解析 OR 优化、案例、网络建模、ABM **必须照列原文模型参数与决策变量**，数据来源写「原文未提及（为模型参数，数值仿真/解析设定）」，**禁止补写原文没有的设定**。
- 「摘要」逐字照抄原文（含原文里的半角标点、全角数字与字形），不删节、不改写、**不做任何归一**；归一（全角拉丁字母/数字转半角）只作用于变量六字段与四段散文。
